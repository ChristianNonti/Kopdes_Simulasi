# 🏪 Kopdes Simulasi 

Game simulasi kasir **Koperasi Desa (Kopdes)** berbasis 3D yang berjalan langsung di browser. Layani pelanggan, hitung belanjaan dan kembalian dengan tepat, jaga stok rak, dan kembangkan gerai sampai jadi kasir terbaik di desa!

> 📚 **Tugas Grafika Game**

## 🎮 Tentang Game

Kamu mengelola sebuah gerai koperasi desa. Gerai mulai dalam keadaan **TUTUP**, jadi siapkan stok barang dulu, lalu buka gerai lewat pintu. Pelanggan akan datang dari trotoar, masuk ke toko, mengambil barang, lalu antre di kasir. Tugasmu: layani mereka secepat dan seteliti mungkin sebelum hari berakhir.

## ✨ Fitur

- 🛒 **Pelanggan dinamis**: datang dari trotoar, masuk lewat pintu, belanja sendiri, lalu antre di kasir.
- 👑 **Pelanggan VIP** (bayar 2x) dan 🥷 **maling** yang harus dikejar.
- 💳 **Kasir interaktif**: hitung total belanjaan dan kembalian dengan benar.
- 📦 **Manajemen stok**: pesan barang, isi rak, dan tambah rak atau kulkas minuman.
- 🎲 **Event harian**: Jam Sibuk, Hari Pasar, Gajian, dan Festival Desa.
- ⬆️ **Upgrade toko**: Mesin EDC, Troli Lincah, Ramah Tamah, dan Kasir Pembantu (NPC).
- ⭐ **Target harian, reputasi, kombo, dan pencapaian**.
- 🌇 **Siklus siang ke senja** dengan lampu jalan yang menyala.
- 🚗 **Jalan raya hidup**: kendaraan lalu lalang dan deretan bangunan di seberang toko.
- 💾 **Simpan otomatis** setiap akhir hari (memakai `localStorage`).

## 🕹️ Kontrol

| Tombol | Fungsi |
| --- | --- |
| `W` `A` `S` `D` / Panah | Bergerak |
| `Shift` | Lari (ada stamina) |
| `E` / `Spasi` | Aksi (ambil barang, buka kasir, buka/tutup pintu, tangkap maling) |
| `P` / `Esc` | Jeda |
| `Enter` | Mulai / lanjut |

Di perangkat sentuh tersedia kontrol layar.

## 📖 Cara Bermain

1. Dekati **pintu** lalu tekan **Aksi** untuk membuka gerai. Waktu hari baru berjalan setelah gerai dibuka.
2. Pastikan **rak terisi stok**. Kalau stok habis, pelanggan pulang dan reputasi turun.
3. Saat pelanggan menunggu di kasir, layani pembayaran dengan **tepat dan cepat**. Makin sabar pelanggan, makin besar bayaran.
4. Awasi **maling** (🥷) dan kejar sebelum kabur.
5. Capai target pendapatan harian, jaga reputasi, lalu belanjakan uang untuk stok dan upgrade.

## ⚙️ Pengaturan Performa

Kalau game terasa berat, buka menu **⚙️ Pengaturan**:

- 🎯 **Preset Cepat**: PC Lemah / Normal / PC Kuat.
- 🖥️ **Resolusi Render**: Asli, 1080p, 720p, 540p, 360p. Ini yang paling berpengaruh ke FPS.
- 🖼️ **Kualitas Grafik** dan 🌗 **Kualitas Bayangan**.
- 🚗 **Lalu Lintas Jalan** dan 🌫️ **Jarak Pandang**.
- 📈 **Resolusi Otomatis** dan batas FPS.
